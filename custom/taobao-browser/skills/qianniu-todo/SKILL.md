# 千牛待办诊断

调用所选店铺专属的 MCP 工具 `read_qianniu_todos`。以这次返回的店铺名称、采集时间和 run ID 标识结果；采集失败则显示失败原因，不回退到其他店铺或上次快照。

1. 依次列出非零的待处理投诉、违规、待售后、待发货、待回复差评、待付款。这个顺序用于人工核查。保留原始数量和加号。
2. 单独列出明确为零的项目和未读到数量的项目。未读到任何数量时提示查看千牛首页。
3. 输出仅覆盖千牛首页当前待办。指标可能重叠，不合计，不推断营业额、近30天趋势或平台时限。

本机执行入口为同目录的 diagnose.mjs。报告只读，可在专家对话中继续分析。
